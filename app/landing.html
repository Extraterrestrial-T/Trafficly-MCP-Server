What Trafficly does

A map UI for agents that need real route context, not plain text directions.

Trafficly gives AI clients a proper navigation surface. The model can compute the route, then render a map with the route geometry, stop labels, route alternatives, and turn-by-turn context.

01

Traffic-aware route planning

Google Routes powers drive-time routing with departure-time handling, distance, duration, and alternative routes.

02

Stopovers stay visible

Named intermediate stops show in the sidebar and on the map, so the route reflects the actual trip the user asked for.

03

Interactive MCP app rendering

The same map resource works across Claude and ChatGPT compatible MCP clients, with text fallbacks when the UI is unavailable.

04

Uber handoff links

Trafficly can prefill pickup, stop, and dropoff data into Uber so pricing, payment, product selection, and booking happen in Uber.

Workflow

Ask in chat. Inspect the map. Choose the route. Continue the ride.

Trafficly is built for MCP clients where text alone is not enough. It gives the assistant structured tools and gives the user a visual route.

1

Ask naturally

"I need to get from Victoria Island to Yaba, stop at Marina, and arrive within two hours."

2

Compute route

Trafficly geocodes places, preserves stop labels, and calculates route alternatives.

3

Render map

The MCP UI draws the route, markers, direction hints, steps, and selectable alternatives.

4

Handoff to Uber

When needed, Trafficly builds a prefilled Uber link for final booking outside the chat.

Install

Connect Trafficly anywhere your MCP client supports remote servers.

Use the MCP endpoint below. Claude supports custom connectors for remote MCP servers, and ChatGPT supports custom MCP apps through Developer Mode where your workspace has access.

MCP server URL

https://trafficly-mcp-server.onrender.com/mcp
First connection requires a Trafficly account. When Claude or ChatGPT connects, Trafficly opens a Clerk OAuth sign-in page. Create an account or sign in, approve access, then return to the chat and enable the Trafficly tools.
Claude remote MCP guide ChatGPT MCP app guide

Claude Web

Go to Claude settings, add a custom connector, paste the Trafficly URL, then click Connect and finish the Clerk sign-in flow.

Customize -> Connectors -> + -> Add custom connector -> https://trafficly-mcp-server.onrender.com/mcp

Claude Desktop

For remote connectors, use Claude Desktop settings the same way as Claude Web. If you use local desktop MCP config instead, route the remote server through mcp-remote.

{ "mcpServers": { "trafficly": { "command": "npx", "args": ["mcp-remote", "https://trafficly-mcp-server.onrender.com/mcp"] } } }

ChatGPT Web

Enable Developer Mode for custom MCP connectors, create a custom app, then provide the Trafficly MCP endpoint when asked for the server URL.

Workspace Settings -> Permissions & Roles -> Connected Data Developer Mode -> Create custom MCP connector -> https://trafficly-mcp-server.onrender.com/mcp

ChatGPT Desktop

Use the same custom app after it is created for your ChatGPT workspace. When prompted, complete the Clerk sign-in flow and enable Trafficly in the conversation.

Open ChatGPT -> select Trafficly from Apps/connectors -> sign in with Clerk -> ask for a route
